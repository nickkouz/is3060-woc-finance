## Track

**Track E: Finance** — How should WOC use data to evaluate capital investments and forecast location-specific ROI?

## Problem Statement

WOC's executive team has no standardized way to measure the return on capital purchases across its three store locations (Downtown SLC, Sandy, Park City). Decisions get made on instinct rather than a consistent financial comparison. Our team is building a capital investment scorecard that projects ROI and payback period by location so leadership can compare purchase decisions on the same criteria.

**Preliminary recommendation:** WOC should build a standardized capital investment scorecard that projects ROI and payback period by store location, so leadership can compare purchase decisions across all three locations using the same financial criteria instead of gut instinct.

## Repository Structure

Each milestone folder holds the lab artifact for that stage of the consulting engagement. Work is committed progressively as each lab is completed, not assembled at the end.

- `milestone-01-tableau-dashboard/` — Lab 1: Tableau dashboard comparing revenue, expenses, and profitability by store.
- `milestone-02-database-schema/` — Lab 2: SQL schema for the capital investment tracker (projected vs. actual ROI, payback period by store).
- `milestone-03-wix-prototype/` — Lab 3: Wix prototype of the ROI scorecard interface, plus cloud/SaaS hosting evaluation.
- `milestone-04-backend-prototype/` — Lab 4: Vibe-coded ROI/payback calculator backend.
- `milestone-05-risk-register/` — Lab 5: Cybersecurity risk register for the data behind the scorecard.
- `milestone-06-implementation-plan/` — Lab 6: Implementation timeline and AI governance plan.

## Final Deliverable

GitHub repository (this repo) plus a live executive consulting presentation (10–12 slides), drawn directly from the artifacts committed here.
